# BLOOM CREATIVES

A responsive graphic design portfolio built with HTML, CSS and JavaScript.

## Project structure

```
bloom-creatives/
├── index.html              # Main homepage — the only root HTML file
├── pages/                  # All secondary HTML pages
│   ├── about.html
│   ├── admin.html
│   ├── contact.html
│   ├── feedback.html
│   ├── gallery.html
│   └── project.html
├── css/
│   ├── style.css
│   └── admin.css
├── js/
│   ├── script.js
│   ├── fx.js
│   ├── contact.js
│   └── admin.js
├── assets/                 # Logos, fonts, photos and gallery artwork
├── robots.txt
├── sitemap.xml
└── README.md
```

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive layouts and interactive visual effects

## Run locally

Open `index.html` in a modern browser, or use the VS Code Live Server extension.

## Deployment

The website is deployed through Cloudflare Pages.

Live website: https://bloom-creatives.pages.dev/
