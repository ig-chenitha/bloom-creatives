# BLOOM CREATIVES

A responsive graphic design portfolio with a monochrome black, white and grey visual identity and a liquid-glass navigation experience.

## Design direction

- Black page canvas with white controls and grey supporting text
- Floating liquid-glass navigation
- Monochrome CSS-rendered sphere hero artwork
- Responsive work, services, about, feedback and contact pages
- Gallery project detail pages and image previews
- Supabase-powered client feedback with administrator review
- Web3Forms-powered contact enquiries
- Responsive mobile navigation and reduced-motion support

## Run locally

Open `index.html` in a modern browser. No build tools or package installation are required.

## Deployment

The production site is deployed with Cloudflare Pages from the GitHub repository's `main` branch.

Live site: https://bloom-creatives.pages.dev/
