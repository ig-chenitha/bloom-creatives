# BLOOM CREATIVES

A responsive graphic design portfolio with an electric-blue, deep-black visual direction and a custom liquid-glass navigation experience.

## Design direction

- Violet + ink palette with a rounded "stage" hero (violet panel, black circle, iridescent chrome sculpture)
- Extended display type (Archivo Black, bundled in `assets/fonts`) with Inter for body text
- Original dependency-free WebGL liquid-chrome hero (`fx.js`), with a 4-colour theme switcher and CSS fallback
- Floating real poster cards, marquee, drag-scroll "Selected works" strip, magnetic buttons, soft cursor
- Fully responsive; honours `prefers-reduced-motion`

## Project structure

```
index.html  about.html  gallery.html  project.html  feedback.html  contact.html  admin.html
style.css   admin.css   script.js     fx.js         contact.js     admin.js
assets/  (logo, symbol, portrait, fonts, gallery posters)
```

## Run locally

Open `index.html` in a modern browser. No build tools or package installation are required.

## Publish with GitHub Pages

The site is a static HTML, CSS and JavaScript project and can be published using GitHub Pages from the repository's `main` branch.

Live site: https://ig-chenitha.github.io/bloom-creatives/
